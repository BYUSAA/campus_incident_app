# Icon assets

Store custom icon files used by the interface in this folder. Prefer Flutter Material Icons when a suitable built-in icon exists to avoid unnecessary assets.

Before adding an icon:
- Confirm the license allows redistribution.
- Declare the file under `flutter/assets` in the root `pubspec.yaml`.
- Check scaling, contrast, and visibility in light and dark themes.
- Use descriptive filenames that explain the icon's purpose.
