# Project documentation

This folder contains the project explanation and submission preparation material.

## Contents

- `technical_report.md`: problem, users, architecture, Firebase data model, access control, state management, UI, test record, limitations, demo-video link, and references.
- `demo_script.md`: suggested 7–10 minute Android demonstration sequence.
- `architecture/`: layer explanation and Mermaid diagram source.
- `screenshots/`: guidance for genuine app and Firebase evidence.

## Finish the submission

1. Generate Android runner files using the local Flutter SDK.
2. Generate Firebase options for the Firebase project used in the demo.
3. Deploy and test the Firestore and Storage rules.
4. Run student and staff workflows on an Android device.
5. Run formatting, analysis, tests, and Android build; record actual results.
6. Add screenshots captured from the real app and Firebase project.
7. Replace the demo-video placeholder in the technical report with the actual accessible link.

Do not invent test results, screenshots, Firebase records, or a video URL.
