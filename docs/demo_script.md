# 7–10 Minute Demo Plan
1. Introduction and campus problem (30–45 sec).
2. Register and verify an ALU test account (1 min).
3. Log in and show home (45 sec).
4. Submit incident with category, description, location and optional photo (1.5 min).
5. Browse, search and filter incidents (1 min).
6. Open details and track status (45 sec).
7. Sign in as separately authorized staff and update status (1.5 min).
8. Show Firebase Authentication, Firestore and Storage records (1 min).
9. Explain architecture, Provider and security rules (1 min).
10. Conclusion (15 sec).

Use test data. Do not show passwords, private keys or other students' private information.
