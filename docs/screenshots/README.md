# Submission screenshots

Place genuine screenshots from the running Android application in this folder. Use the filenames listed in `../technical_report.md` where possible.

Recommended evidence includes:

- Login, registration, and email verification screens.
- Home dashboard and incident creation form, including a photo selected.
- Student incident list with search/filter and the report details view.
- Staff dashboard and status update control.
- Firebase Authentication, Firestore, and Storage records for the test workflow.

Capture the actual app and Firebase project. Do not create mock screenshots or use example records as proof of a successful backend workflow. Hide private email addresses, user IDs, credentials, and other personal information before submission.
