## Evidence checklist

- Capture the app running on the Android device/emulator used for the demo.
- Use test data created for this project.
- Make the report title, category, location, and status readable.
- Show the photo selection/upload path.
- Show student and staff views using separate test accounts.
- Hide email addresses, UIDs, passwords, tokens, sensitive download URLs, and private project details.
- Do not show another student's private records.
- Use clear filenames and keep original image resolution.

The suggested paths are referenced in [the technical report](../technical_report.md). After adding images, verify that every referenced screenshot exists and demonstrates the stated workflow.
