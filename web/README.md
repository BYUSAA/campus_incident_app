# Web platform notes

Web is not the target platform for the mobile incident-reporting demonstration. The repository includes shared Flutter code; Firebase options for web are not generated by default.

To add web support for optional testing, run from the repository root:

```bash
flutter create --platforms=web .
flutterfire configure --platforms=web
flutter run -d chrome
```

Do not use a browser-only run as evidence of the Android mobile workflow. Check camera/gallery behavior, Firebase configuration, and security rules on the Android device used for the final demonstration.
